# Mukesh Power & Energy (Full-Stack Project)

Clean Energy & Power Management Platform.

## 📁 Project Structure

```
mukeshpowe&energy/
├── frontend/               # React 19 + Vite Frontend
│   ├── src/
│   │   ├── services/api.js # Backend integration helper
│   │   ├── App.jsx         # Main UI component
│   │   ├── App.css         # Styling
│   │   └── main.jsx
│   ├── package.json
│   └── vite.config.js
└── backend/                # (Future) Express / Node.js / Python API
```

---

## 🚀 How to Run Frontend

1. Open terminal in the project root:
   ```bash
   cd frontend
   npm run dev
   ```
2. Open the URL shown in the terminal (usually `http://localhost:5173`) in your browser.
